# Trader Can Verify System Is Live and Ready for Trading

## As a
Trader

## I want
to log in and immediately see whether the system is live and I am permitted to trade

## So that
I can safely decide whether to start trading or stop

---

## Acceptance Criteria

- [ ] My identity is authenticated successfully
- [ ] My role is identified as Trader
- [ ] My trading permission status is clearly shown (Enabled / Disabled)
- [ ] The current trading environment is clearly visible (PROD / UAT)
- [ ] Market data connection status is shown as Live or Not Live
- [ ] The timestamp of the latest market data is visible
- [ ] System time is displayed and aligned with the trading venue
- [ ] Emergency kill switch status is clearly indicated
- [ ] If any required status is not valid, trading actions are disabled
