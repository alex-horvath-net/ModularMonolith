	This is a strickly sequential development model,
	which is based on the vision of the application user and the business strategy to achieve the business goal. 
	It is a linear process, which starts with the vision and ends with the implementation of the solution.
	The main idea is to focus on the ultimate goal of the application user and 
	to build a solu0tion that will help them achieve that goal in the most efficient way possible. 
	The development process is divided into several steps, which are described below:

	Session start protocol:
	- Command: `dev start`
	- Required first action: read this file.
	- Required log action: append `dev started - dd.MM.yyyy hh:mm:ss` to `docs/log.md`.


- Identify the application and the application user.</br> 
  Document it in {VisionName}.md.
- Vision the ultimate goal of the application user.</br>
  Document it in {VisionName}.md.
- Identify simplest sequence of existing correct user interactions,</br> 
  which get the application user the closest to their ultimate goal.</br> 
  So this sequence finishes just before the user interaction what we will modify or add later.</br> 
  Document it {VisionName}.md 
- Make an educated guess what will be the very last user interaction,</br>
  which will lead directly to the ultimate goal of application user.</br>
  This user interaction might be doesn’t exist yet Document it {VisionName}.md 
- end point—the ultimate business goal of the application user, what they to achieve, the final destination.
Identify the business strategy, to achieve the business goal in form of simple name and sequence of supposed user interactions.
